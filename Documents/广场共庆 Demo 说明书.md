# 《广场共庆》Unity Demo 说明书

版本：2026-09-20。本文描述**当前可运行原型已经实现的内容**，供观看视频、打开项目或面试交流时快速理解作品；玩法设想与取舍的详细推导见[策划案](./Unity%20Demo%20策划案.md)。

## 作品概览

这是一个在广场共建庆典蛋糕的 Unity 单机交互 Demo。场景里同时有红、黄、蓝三名角色，由一人切换操控，模拟不同玩家路过、接力和加入公共活动。玩家可在各自家园取得水果、到商店买鸡蛋，在广场捐献、协作加工、装饰蛋糕，也能买筷子偷吃和抓捕。任意角色可主动举办庆典，观看共同表演与结果，再回家放置奖杯、查看自己的行为回顾。

Demo 的完整体验循环是：

**个人准备 → 公共贡献 → 协作制作与改造蛋糕 → 趣味冲突 → 庆典结算 → 家园留念。**

## 实际完成的功能与画面表现

| 模块 | 当前功能 | 可见反馈与表现 | 设计原因 |
|---|---|---|---|
| 三角色与镜头 | 1/2/3 或点击角色状态卡切换红、黄、蓝三名角色；仅当前角色接收移动与交互。镜头保持俯视角度和视野大小，平滑跟随被选角色。 | 左上角色卡显示主控箭头、移速、筷子倒计时、加工或减速状态；切人时镜头平移。 | 用单机方式演示“有人先做、有人路过加入、后来者看到结果”的社交节奏。 |
| 场景与动线 | 三个角落为角色家园，第四角落为鸡蛋商店，中央是广场和蛋糕。广场按捐赠、加工、成品、交易等区域布置，木牌标识地点。 | 三处家园、各自果树、商店货架、分区牌和广场交互点；交互物有碰撞。 | 将私人获得物品和公共制作放在一条容易理解的往返路径上。 |
| 领取、购买、捐献 | 家园苹果/香蕉/橘子树可领取对应水果；商店可购买鸡蛋；广场四种原料堆可捐献。家园外新增的同类树也可交互。 | 靠近有效目标后出现 `[F]行为`，可按 F 或点击交互提示；角色头顶增减飘字、左下 log 记录对应动作。 | 让家园、商店和广场彼此产生联系，让日常行为成为公共活动的入口。 |
| 两种加工与协作 | 切水果、打发奶油是两个独立工位。单人一批约 10 秒，人数越多实时加速；同一角色不能重复加入同一批。切人后工位继续计时，加工中的参与者移速为 0。 | 工位运行时持续显示共享进度条；完成时分别产生果切或奶油，并显示角色成功飘字与公共产出日志。 | 把协作直接转成可感知的时间收益，并保持短时加入的低门槛。 |
| 六扇区蛋糕 | 蛋糕由六个 60° 扇区组成；三处贴果切、三处抹奶油，交替分布。每处均可独立按 F 操作，不要求先在工位生产对应成品。 | 贴果切后出现/替换果切装饰；抹奶油后整个扇区切换颜色。 | 让公共作品始终保持可编辑，后来者能立即看见前人留下的变化。 |
| 筷子、偷吃与抓捕 | 购买限时筷子后，水果/鸡蛋堆的 F 自动从“捐献”变为“偷吃”，果切/奶油堆也可偷吃。偷吃逐次减速，最低 0，每次刷新约 10 秒减速时间；偷吃后的角色在约 10 秒内可被另一名持筷子的角色靠近按 E 抓捕。 | 角色卡显示筷子剩余时间、当前移速与减速；右下出现独立的 `[E]抓捕` 提示，成功/失败写入日志与飘字。 | 给轻松共建加入可被旁人发现的小插曲，而不阻断主要制作流程。 |
| 行为反馈与日志 | 交互只在条件满足时显示提示；不同角色的行为以各自颜色记录，物品与数量变化另作颜色区分。最近记录显示在左下 log，完整记录保留在本轮会话内。 | 角色头顶短暂飘字，深色底框保证建筑旁可读；加工进度、交互提示、F/E 提示分开表现。 | 让同步看到的动作和异步留下的痕迹都有明确归属。 |
| 庆典演出与结算 | 任意角色在庆典触发器按 F。主 HUD 显示 5 秒倒计时；镜头逐渐放平，三人自动走到蛋糕前；随后约 5 秒简化烟花与 `HappyBirthday`，结束后打开结算界面。 | 结算显示三人的参与称号、每人奖杯 +1、筷子售卖金币池与随机红包分配。再次触发只查看本次结果，不重复颁奖。 | 把分散的日常贡献汇成一个被共同见证的时刻。 |
| 称号与奖励 | “大师”对应参与加工，“艺术家”对应装饰蛋糕，“馋鬼”对应偷吃，“慈善家”对应捐献，“捕头”对应成功抓捕。称号按是否参与结算，不做次数排名；三名角色无论是否取得称号，庆典后各得一座奖杯。 | 庆典结果页逐人列出称号和奖杯；参与过准备或制作的角色可参与筷子金币池的随机红包分配。 | 承认不同的参与方式，也避免用排名把共建活动变成竞争。 |
| 家园留念 | 每名角色回到自己家门口放置奖杯；再次 F 查看本人活动记录，可滚动浏览并关闭。 | 家园奖杯模型出现，回顾页显示个人称号与本轮行为历史。 | 让公共活动结束后仍留下与个人有关的记忆物。 |

## 操作与体验入口

- Unity 场景：`Assets/Scenes/CelebrationPrototype.unity`，打开后进入 Play。
- **WASD / 方向键**移动；**1/2/3** 或点击左上角色卡切换主控。
- 靠近目标时使用 **F** 或点击右下交互提示；持筷子靠近另一名角色时使用 **E** 或点击抓捕提示。
- **Esc** 或界面关闭按钮关闭结算/回顾；界面关闭时按 **R** 重置本轮。
- 建议按“家园领取/商店购买 → 广场捐献 → 双人加工 → 蛋糕装饰 → 买筷子偷吃/抓捕 → 举办庆典 → 回家放奖杯”体验。详细步骤见[运行说明](./灰盒Demo运行说明.md)。

## 原型范围与实现取舍

本作品以**可操作、可观察的一轮完整体验**为目标。三角色由同一输入设备轮流控制，用于演示同步加入工位与异步留下行为痕迹；当前没有联网房间、真人多端同步或服务器状态。物品与金币只记录每次行为的增减，不做可耗尽的背包与总库存，蛋糕装饰也不因缺料而失败。活动数据、称号和日志保存在当前运行会话中，重置或退出后不做磁盘持久化。

场景与演出主要由基础几何体、简单材质、UI 和粒子效果组成。当前实现的是固定场景与一轮庆典；策划案里提出的昼夜、天气差异和更自由的蛋糕造型，不属于这版已完成内容。这个范围让观众可以在短时间内从一个可见行为走到共同庆典与个人回顾，同时清楚看到设计逻辑和实际交互反馈。
