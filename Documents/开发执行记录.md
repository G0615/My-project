## 本轮固定代码接口

全部新代码使用命名空间 `CelebrationDemo`。核心不依赖 Unity，路径 `Assets/CelebrationDemo/Core/`；组件分别在 `World/`、`UI/`、`Runtime/`；场景工具在 `Assets/CelebrationDemo/Editor/`。

### 核心（core agent 所有）

- `enum TargetKind { HomeFruit, ShopEgg, FruitPile, EggPile, SlicedFruit, CreamPile, CutStation, WhipStation, Chopsticks, CakeFruit, CakeCream, Celebration, Trophy }`
- `[Serializable] class TargetSpec { public string Id; public TargetKind Kind; public int Index; public int OwnerActorId; }`。Index 为 0～2，OwnerActorId 仅奖杯需要；工位 ID 固定 `cut` / `whip`。
- `class DemoConfig`：可配置 WorkSeconds=10, BaseSpeed=10, ChopsticksSeconds=60, SlowSeconds=10, MaxSlowStacks=10。
- `enum TrophyStatus { Unawarded, Awarded, Placed }`；`enum TitleKind { Master, Artist, Glutton, Philanthropist }`。
- `ActorState`：ActorId, ChopsticksExpiresAt, SlowStacks, SlowExpiresAt, 四个参与布尔 HasCraftParticipation/HasArtParticipation/HasEaten/HasDonated, TrophyStatus, GrantedTitles（TitleKind[]）。
- `StationState`：Id, Progress(float 0～1), IsRunning, BatchId(int), ParticipantIds（只读或列表，元素int）。
- `CakeState`：FruitStyles(int[3]，初值0), CreamColors(int[3]，初值0), FruitAuthors/CreamAuthors(int[3])。
- `ActionEvent`：ActivityId(string), Sequence(long), EventId(string), Time(double), ActorId(int), ParticipantIds(int[]), TargetId(string), Message(string，中文完整日志), ActorText(string), TargetText(string), NewlyQualifiedTitles/GrantedTitles(TitleKind[])。ActorId 为0表示共享事件，颜色由参与名单处理。
- `InteractionOffer`：Label(string), CanExecute(bool)。`ActionOutcome`：Message(string), OpenHistory(bool), OpenCelebration(bool), ActorId(int)。
- `DemoSession(DemoConfig config = null)`；公开 Config, Now(double), ActivityId, HasCelebrated, CutStation, WhipStation, Cake, History(IReadOnlyList<ActionEvent>)。
- `GetActor(int)` / `GetSpeed(int):float` / `HasChopsticks(int):bool` / `Resolve(int,TargetSpec):InteractionOffer` / `Execute(int,TargetSpec):ActionOutcome` / `Advance(double now)` / `GetHistory(int):IReadOnlyList<ActionEvent>` / `Reset()`。
- `event Action<ActionEvent> EventRecorded`。先保存历史再通知；协作完成的公共产出只记一次，完整参与名单可供三人各自查询。
- 所有业务时间通过 Advance 推进到 Now，Execute 不自行读取系统时间；Reset 后 Now=0。无任何库存或金币余额。

### 世界（world agent 所有）

- `ActorView : MonoBehaviour`：public int ActorId; public Transform HeadAnchor; `Move(Vector2 input,float speed,Camera camera)`，仅受调用时移动；`SetActiveVisual(bool)`；`ResetPosition()`；出生位置由 Awake 记录。
- `TargetView : MonoBehaviour`：public TargetSpec Spec; public string DisplayName; public Transform FeedbackAnchor; public float InteractionRadius=2.4f; `SetHighlighted(bool)`；`ApplyState(DemoSession)`，负责蛋糕外观/奖杯/工位工具等状态表现。
- `FixedAngleCamera : MonoBehaviour`：`SetTarget(Transform,bool immediate=false)`，固定旋转/缩放，只平滑平移；所在物体挂Camera。
- `CelebrationSceneBuilder.Create()` 静态编辑器菜单及批处理入口，创建并保存新场景，显式挂载下面 Runtime/Hud 并设置引用；设置构建首场景。幂等重建仅限本工具生成的新场景，不覆盖原有 CelebrationDemo。
- 场景需有可达、分离的全部点位、蛋糕六个60°交替目标、三人独立底座与苹果点。不能添加旧 PlayerController/PlayerInteractor 以免多路输入。

### UI（ui agent 所有）

- `DemoHud : MonoBehaviour`：`Initialize(DemoRuntime)`；`OnAction(ActionEvent)`；`ShowHistory(int)`；`ShowCelebration()`；`CloseModal()`；`ResetView()`；public bool IsModalOpen。
- 可以运行时生成 Canvas 与 UI；中文字体采用本机可用中文字体或显式资源，避免新依赖。支持实际鼠标按钮和滚动，InputSystem UI 输入。
- Hud 从 Runtime 读取 Session / ActiveActorId / CurrentTarget / Actors / Targets / CameraRig；不直接改核心状态。每帧刷新提示/效果/进度；所有 F 只由 Runtime 转发。
- OnAction 同色日志和角色/目标飘字；共享完成只一份公共产出，按名单处理角色反馈。最近100条窗口不清核心历史。奖杯回顾完整列表按 Session.GetHistory 查询。

### 集成（主 agent 所有）

- `DemoRuntime : MonoBehaviour`：public ActorView[] Actors; public TargetView[] Targets; public FixedAngleCamera CameraRig; public DemoHud Hud; public DemoSession Session { get; private set; }; public int ActiveActorId { get; private set; }; public TargetView CurrentTarget { get; private set; }。
- Awake 创建 Session，Start 初始化引用/Hud；Update 推进时钟、读1/2/3、WASD、F、Esc；LateUpdate/世界各自刷新表现。重置快捷键 R 必须明示，公开 `ResetDemo()`，`SelectActor(int)`，`Interact()`。
- 背景工作在切人/回顾界面开启时继续；UI 阻挡移动/F，切换先关；角色位置选择目标，奖杯只选择本人；目标稳定、单次 F 单操作。
