# A04 唯一输入与角色切换记录

日期：2026-09-19。范围：`CelebrationPrototype` 场景中共享键盘输入、1/2/3 角色切换和切换后的移动路由；不包含镜头平滑跟随、F 目标选择、UI 美化或正式玩法。

## 实现

- `DemoRuntime` 是唯一读取 `Keyboard.current` 的输入入口。WASD 与方向键仍在 Runtime 中合并，并通过 `Vector2.ClampMagnitude(..., 1f)` 保持斜向速度上限。
- 数字键 1/2/3 及小键盘 1/2/3 调用现有 `SelectActor`，更新 `ActiveActorId`、镜头目标、选中环，并关闭当前回顾弹窗；切换帧不把残留按键当作移动输入。
- Runtime 每帧只向 `ActiveActorId` 对应的 `ActorView` 调用 `Move`。其他角色对象、组件和 Transform 保持启用与原位置，不通过禁用角色对象来隐藏非主控角色。
- 场景验证补充默认主控和角色对象启用检查；烟测覆盖 1→2→3→1 连续切换、WASD/方向键移动和非主控位置保持。
