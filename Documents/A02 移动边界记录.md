# A02 单角色移动与边界记录

日期：2026-09-19。范围：`CelebrationPrototype` 场景中的主控角色移动、斜向速度和可行走边界；不包含角色编号扩展、角色切换、镜头跟随、F 交互或 UI 美化。

## 现有实现核对

- `DemoRuntime` 从 Input System 读取 WASD 与方向键，只把移动向量投递给 `ActiveActorId` 对应的 `ActorView`。
- 输入在 `DemoRuntime` 中经过 `Vector2.ClampMagnitude(movement, 1f)`；`ActorView` 按相机水平面组装方向并再次归一化，因此斜向移动不会超过单轴速度。
- `ActorView` 通过 `CharacterController.Move` 移动，未引用旧 `PlayerController` 或 `PlayerInteractor`。
- 场景地面为 `44 x 34` 的带碰撞体地块，四边围栏位于 `x = ±21.8`、`z = ±16.8`，均带 `BoxCollider`；角色控制器的半径为 `0.42`，无法越过围栏。
