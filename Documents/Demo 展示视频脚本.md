# 《广场共庆》Demo 展示视频脚本

版本：2026-09-20。依据当前 Unity 场景与运行代码编写。目标成片约 **3 分 30 秒至 4 分钟**，以游戏实录为主体，口播可改为同内容字幕。录制时按实际画面微调时间，不为凑时长等待角色横穿地图；跨区域移动可剪掉中段。

## 视频要传达什么

一个人控制三名角色，模拟广场里不同玩家在不同时间加入公共活动。观众应依次看到：**从家园与商店带来物品 → 公共区域捐献、加工与装饰 → 偷吃与抓捕的小插曲 → 主动举办庆典 → 回家留下可查看的纪念物**。红、黄、蓝三色的角色状态、日志和飘字，负责让“谁做了什么”始终清楚。这里的社交是本地三角色模拟，不宣称已实现联网多人。

## 录制准备

1. 在 Unity 打开 `Assets/Scenes/CelebrationPrototype.unity`，将 Game 视图设为 **16:9**，进入 Play。录制时隐藏 Unity 编辑器边框或只裁切 Game 视图。
2. 按 **R** 重置一次活动，确认三名角色、场景和日志处于初始状态。左上三张角色卡可点击切人；**1/2/3** 也可切换。**WASD/方向键**移动，靠近可交互点后按 **F** 或点击右下交互提示，抓捕用 **E** 或点击对应提示。
3. 先排练行走路线。三处家园在场景三个角落，鸡蛋商店位于第四角，广场中央按“捐赠区—加工区—成品区—蛋糕”安排。镜头会跟随当前角色，跨区移动建议后期跳剪。
4. 预留一次完整的庆典镜头：触发后有 **5 秒倒计时、5 秒烟花**，中途不要停止录屏。烟花完毕才弹结算页。
5. 若要展示**抓捕成功**，先让一名角色购买筷子并偷吃，再让另一名已持筷子的角色在偷吃后 **10 秒内**靠近前者按 E。两名角色最好提前在同一区域准备；如果实际操作超时，按 R 重录这个片段。筷子购买金币会进入庆典红包池。

## 剪辑和录音提示

- 开头和结尾各保留一个完整的广场画面。其余尽量用真实游戏画面证明功能，避免长段菜单或代码录屏。
- 加工段必须拍到**第二人加入前后**的进度速度变化；只拍进度条完成不足以说明协作。不同角色在工位附近时再切换，减少空镜等待。
- 交互画面停留到飘字和日志足够读清；角色卡、场景提示、进度条、日志至少各给一次清晰特写。
- 庆典段不要加速或切断；烟花结束后结算弹窗的先后关系是整个循环的收束。
- 结算页只解释实际达成的称号。如果视频没有录到成功抓捕，口播不要说“已获得捕头”，可只展示 E 抓捕的功能或删去抓捕口播。
- 结尾字幕建议写：**“Unity 单机交互原型｜三角色模拟同步/异步参与｜本轮状态不做联网与持久化”**。

## 最低可用短版

如果最终只保留约两分钟，优先剪成：**角色切换与捐献（20 秒）→ 双人切果和打发（35 秒）→ 蛋糕变化与偷吃（25 秒）→ 完整庆典演出（20 秒）→ 结算、奖杯回顾（20 秒）**。抓捕与红包可放在补充片段，不要压缩庆典倒计时与烟花。
