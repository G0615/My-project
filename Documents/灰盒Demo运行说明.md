# 庆典灰盒 Demo 运行说明

本版用基础几何体实现玩法与反馈。三个角色模拟同场参与；所有行为保存在本次运行内，退出或重置后清空。

## 入口

- Unity 场景：`Assets/Scenes/CelebrationPrototype.unity`。
- Windows 构建目标：`Builds/CelebrationDemo/CelebrationDemo.exe`。
- 首次生成或重新生成本版场景：编辑器菜单 `Tools > Celebration Demo > Create Celebration Prototype`。生成器只重建此灰盒场景，手动调整此场景后需留意覆盖。

## 操作

| 按键 | 操作 |
|---|---|
| WASD / 方向键 | 移动当前角色 |
| 1 / 2 / 3 | 切换红 / 黄 / 蓝角色，镜头平滑跟随 |
| F | 执行当前高亮地点的动作 |
| Esc / 关闭按钮 | 关闭庆典或个人回顾界面 |
| R | 界面关闭时重置本轮活动、角色位置、奖杯和日志 |

没有捐献/偷吃模式切换键。持有筷子时，水果/鸡蛋堆的 F 自动变成偷吃；筷子到期后恢复捐献。其他地点不受此限制。

## 建议体验顺序

1. 家园领苹果、到水果堆捐献；切换角色到商店买蛋、到鸡蛋堆捐献。
2. 1 号加入切果，再切 2、3 号加入，观察共享进度加快。角色走开和切人均不打断加工。
3. 加入打发；到筷子点购买后偷吃，观察速度下降及十秒恢复。
4. 绕蛋糕给三个挂点贴水果，为另外三个区域抹奶油。无需拿取材料，也无需等待加工完成。
5. 到广场庆典台按 F，查看三人的称号与奖杯反馈；无称号的角色也获奖杯。
6. 各自到家园对应颜色的底座 F 放置奖杯，再 F 查看自己的完整行为记录。关闭后结束体验。

单人十秒工位；筷子默认六十秒；每次偷吃刷新全部减速的十秒期限。配置集中在场景 DemoRuntime 的 Settings 中。

## 开发边界

本版不含真实联网、磁盘存档、物品库存与金币余额、昼夜天气和正式角色动画。日志里的数量是每次动作的增减反馈。已完成的验证和构建结果见[开发执行记录](./开发执行记录.md)。
